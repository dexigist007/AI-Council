# ADR-0001: 100'lük skor yerine karar + rubrik
Durum: Kabul edildi

Modeller arası sayısal skorlar tutarsızdır ve sahte kesinlik verir. Fikir raporu karar
(BUILD / VALIDATE / HOLD / REJECT) ve boyut bazlı rubrik (problem netliği, talep kanıtı, fizibilite,
efor, risk; düşük/orta/yüksek + gerekçe) içerir. Genel skor gerekirse rubrikten türetilir.
